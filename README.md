
# CS 300: Data Structures and Algorithms

This repository contains my coursework from CS 300 at Southern New Hampshire University. It includes my Project One analysis of data structures and algorithms and my Project Two C++ program for organizing and displaying college course information.

## Project One: Data Structures Analysis and Design

In Project One, I evaluated vectors, hash tables, and binary search trees to determine which data structure would best support a college advising program. I compared their efficiency, advantages, disadvantages, and memory requirements. I recommended a binary search tree because it allows courses to be organized by course number and displayed in alphanumeric order using an in-order traversal.

## Project Two: ABCU Advising Assistance Program

In Project Two, I developed a C++ program that uses a binary search tree to store and organize course information from a CSV file. The program allows users to load course data, print an alphanumeric course list, search for individual courses, and view prerequisite information. I also implemented an additional feature that creates a suggested course schedule with prerequisites listed before the courses that require them.

## Reflection

### What was the problem you were solving in the projects for this course?

The main problem was determining how to organize and retrieve course information efficiently for an academic advising program. The program needed to store courses, display them in alphanumeric order, and provide prerequisite information to help students plan their schedules. Project One focused on evaluating different data structures, while Project Two involved developing a working solution in C++.

### How did you approach the problem? Consider why data structures are important to understand.

I approached the problem by comparing vectors, hash tables, and binary search trees before choosing a data structure for the program. I considered how each structure stores information, how efficiently it searches for courses, and whether additional sorting would be needed. Understanding data structures is important because the structure selected can affect a program's performance, memory usage, and overall design.

### How did you overcome any roadblocks you encountered while going through the activities or project?

One of my challenges was working through C++ syntax errors and making sure the program's functions worked together correctly. I also had to make sure the CSV file loaded properly and that prerequisite information was displayed accurately. I addressed these challenges by reviewing my code, correcting errors, rebuilding the program, and testing each menu option. Testing smaller sections helped me identify problems and confirm that my changes worked.

### How has your work on this project expanded your approach to designing software and developing programs?

These projects helped me understand the importance of planning a program before writing the code. Instead of focusing only on making the program work, I learned to consider how information should be stored, searched, and displayed. Comparing different data structures showed me that there can be multiple ways to solve the same problem, but some approaches are better suited to specific requirements.

### How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

I have become more intentional about organizing my code into smaller functions, using meaningful names, and adding comments that explain what each section does. In Project Two, separating the binary search tree operations, file loading, and menu options made the program easier to understand and test. I also learned that checking user input and validating data can help prevent errors. These practices will help me develop programs that are easier to maintain, troubleshoot, and update in the future.
